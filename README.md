# Hanzala Kareem's Portfolio

A modern, fast, and responsive portfolio built with [Next.js](https://nextjs.org/) (App Router), [Tailwind CSS v4](https://tailwindcss.com/), and [Framer Motion](https://www.framer.com/motion/).

## Tech Stack
- **Framework**: Next.js (App Router)
- **Styling**: Tailwind CSS v4
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **UI Components**: Radix UI

## Getting Started

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Run the development server:**
   ```bash
   npm run dev
   ```

3. **Open [http://localhost:3000](http://localhost:3000)** in your browser to see the result.

## SEO and Performance
This site is optimized for performance and SEO out of the box. It implements JSON-LD schema markup (`ProfilePage`, `CollectionPage`, `Blog`, `Person`) and properly configures OpenGraph tags for rich social media sharing. 

## Deployment
The easiest way to deploy your Next.js app is to use the [Vercel Platform](https://vercel.com/new).

Since this is a standard Next.js application, it will deploy seamlessly on Vercel without requiring custom configuration.
